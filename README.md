# Locations

- All 4 Bowser fights (the fifth Bowser fight is the goal).
- All 27 graffiti spots (activated using Bowser Jr.).

# Goal
Receive 50 Cat Shines and beat the final Bowser fight.

# Options
## Lock Powerup Abilities
If enabled, you will have to find powerup abilities on top of having to find the powerups.
For example, you will have to find Throw Fireballs (Fire) and Fire Flower.
If disabled, you will start with all the powerup abilities, and just have to find the powerups.

## Lock Dive (Plessie)
If enabled, you will have to find Dive (Plessie).
Dive (Plessie) is not a progression item, and just makes swimming with Plessie faster.

## Extra Cat Shines
How many extra Cat Shines will be in the item pool.
Having the above two options disabled frees up 10 and 1 slots in the item pool respectively.
If both are enabled there will be 12 free item slots for extra Cat Shines to be placed into.
If both are disabled there will be 23 free item slots for extra Cat Shines to be placed into.
Amount of extra Cat Shines added will be decreased to fit within the item pool if either of the options are enabled.

# Other Info
Intended to be played from a new save file. You start with Fur Step Island unlocked, and one of the first three areas (Scamper Shores, Fort Flaptrap, and Pounce Bounce Isle) unlocked.
## Known Issues
Generation fails sometimes, but this has only happened to me when generating a single game seed.
